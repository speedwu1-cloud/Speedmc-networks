# Site Speedrun — TOP 50

Site statique prêt pour GitHub Pages.

## Modifier les joueurs
Ouvre `script.js` et modifie la liste `players`.
Exemple :
`{name:"Yelui7", wins:42, bestTime:"18:32"}`

Les places restantes sont déjà créées automatiquement.

## Tester
Ouvre `index.html` dans ton navigateur.

## Mettre en ligne gratuitement
1. Crée un dépôt GitHub public.
2. Envoie `index.html`, `style.css` et `script.js`.
3. Dans Settings > Pages, choisis le déploiement depuis la branche principale.
4. GitHub Pages te donnera l'adresse du site.

Le classement, la recherche, le tri et le podium fonctionnent sans serveur.
